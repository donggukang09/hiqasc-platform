회원 SP 입고 관리(임대) 처리

임대머신 반납 시 함께 잘못 반송된 회원 개인 SP를 기록하고, 콜센터에 안내 메일을 보내 회원에게 돌려주는 흐름입니다.
3 STEPS 지원팀 도구 열기 ↗
1입고 등록 2전체 내역 · 검색 3콜센터 메일 발송
회원이 임대머신을 반납할 때 물통 · 컵받침 등 개인 SP를 함께 잘못 반송하는 경우가 있습니다. 이를 택배로 돌려주기 위해 입고 기록 → 콜센터 안내 → 출고 처리 순서로 진행합니다.
1입고 등록 › 3콜센터 메일 › 2출고완료 변경
1

입고 등록

입고된 SP의 정보를 입력하고 저장합니다.

항목 입력

입고일자

2

전체 내역 · 검색

등록 확인과 상태 관리를 합니다. 미처리 건을 찾는 용도입니다.

확인

등록 확인

저장이 정상적으로 되었다면 아래 리스트에 바로 나타납니다. 등록 직후 목록에서 확인하세요.

클릭하면 확대
검색 조건 5개 · 등록된 내역 목록
상태

상태 변경

대기중 아직 회원에게 발송되지 않음 › 출고완료 택배 발송 완료

실제로 택배가 나가면 목록의 상태 드롭다운에서 출고완료로 바꿉니다. 선택하는 즉시 저장되며 별도 저장 버튼은 없습니다.

상태를 바꾸지 않으면 미처리 건으로 남습니다. 이 기능의 목적이 누락 없이 회원에게 돌려주는 것이므로, 발송 즉시 바꿔주세요.
미처리 건 확인법 — 상태 검색을 대기중으로 두면 아직 발송되지 않은 건만 모아 볼 수 있습니다. 주기적으로 확인하세요.
비고도 목록에서 바로 수정할 수 있습니다. 입력 후 다른 곳을 클릭하면 저장됩니다. 검색은 입고일자 · 박스번호 · 회원번호 · 회원명 · 상태 5개 조건을 조합할 수 있습니다.
3

콜센터 메일 발송

당일 입고 건을 콜센터에 안내해 회원 반송을 요청합니다.

발송

발송 절차

오늘 입고된 SP가 있으면 콜센터로 안내 메일을 보냅니다.

  • 대상 날짜를 선택하고 [불러오기]를 클릭합니다.
  • 해당 날짜의 입고 건이 목록으로 나옵니다. 보낼 건만 체크합니다. (기본 전체 선택)
  • 필요하면 비고를 그 자리에서 수정합니다.
  • 아래 미리보기에서 받는사람 · 제목 · 본문을 확인합니다.
  • [콜센터에 메일 발송]을 클릭합니다.
클릭하면 확대
날짜 선택 → 대상 체크 → 미리보기 확인 → 발송
참고

메일 정보

제목

미리보기 = 실제 발송 내용입니다. 체크나 비고를 바꾸면 미리보기도 즉시 바뀌므로, 보이는 그대로 나간다고 보면 됩니다.
발송 버튼을 누르면 즉시 외부로 나갑니다. 콜센터와 네스프레소로 바로 전달되므로 취소할 수 없습니다. 발송 전 회원번호 · 내용물을 다시 확인하세요.
이후

발송 후 처리

메일 발송은 콜센터 안내까지입니다. 실제 택배가 나가면 2번 전체 내역으로 돌아가 해당 건의 상태를 출고완료로 바꿔야 처리가 끝납니다.
