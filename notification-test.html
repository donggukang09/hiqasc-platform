탭 이름: 알림

A열: id — 알림 번호 (1, 2, 3...)
B열: title — 알림 제목
C열: message — 알림 내용
D열: type — 알림 유형 (info / success / warning)
E열: active — TRUE면 표시, FALSE면 숨김

🔧 사용 방법

1. Google Sheets에서 알림 탭에 새 행 추가
2. id, title, message, type, active(TRUE) 입력
3. 최대 1분 이내에 접속 중인 모든 페이지에 팝업 표시
4. 알림을 끄려면 active를 FALSE로 변경
