DEVELOPED BY DONGGU KANG

📋 사용 방법

  1. 출고일 기준 파일 엑셀 다운로드 후 (시트1: 로우데이터, 시트2: Model)
    드래그 앤 드롭하거나 클릭하여 업로드
  2. Serial Number를 텍스트 입력란에 붙여넣기 (한 줄에 하나씩)
  3. "DOA 시트 생성" 버튼 클릭
  4. 생성된 Excel 파일 자동 다운로드

💡 간단 사용법:
DOA 자료용 엑셀 파일(로우데이터 + Model 시트)을 업로드하고, DOA로 판정된 Serial Number를 붙여넣은 후 생성 버튼만 누르면 자동으로 정리된 엑셀 파일이 다운로드됩니다.
